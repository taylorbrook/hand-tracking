Max/MSP Integration Instructions

  1. Install Node for Max from the Max package manager
  2. In the Max patch, click script npm install once, then script start to run the WebSocket bridge ([node.script hand-bridge.js], port 8080)
  3. Click Start Camera on this page; landmark data is streamed to the bridge over WebSocket
  4. The bridge outputs one list per landmark: hand_index handedness landmark_index x y z (21 landmarks per hand), and nohands when all hands leave the view

Landmark Indices:

  • 0: Wrist
  • 1-4: Thumb (CMC, MCP, IP, Tip)
  • 5-8: Index Finger
  • 9-12: Middle Finger
  • 13-16: Ring Finger
  • 17-20: Pinky
